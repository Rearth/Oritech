---
title: Wrench
icon: oritech:wrench
---

The wrench is a tool which can be used to edit and break pipes. When used on a pipe connection, and will change the connection type. For example, if used on the north connection of a pipe, it will change only the north connection type.

Types of connections:
- **Not Connected:** The pipe will not be connected to a neighboring block or target interface (machine, chest, fluid container, etc.)
- **Connected:** The pipe will be connected to a neighboring block or target interface.
- **Extract:** The pipe will extract items/fluids from the neighboring block or target interface.

Additionally, the wrench can be used to break pipes at a quicker speed.
