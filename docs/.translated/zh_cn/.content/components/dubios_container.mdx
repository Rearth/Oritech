一种强化容器，用于储存不稳定流体、挥发性化合物，
以及其他大多数Oritech机器无法直接处理的材料。

**用途**
- **捕获实体**：可捕获会飞的小型魔法生物的大脑，
从而获得[堕落智能](@oritech:unholy_intelligence)。
- **加工处理**：可以在离心机装填[奇异物质](@oritech:fluid_strange_matter)。
- **合成**：用于高级配方，如[超导体](@oritech:superconductor)、
[极致机器核心](@oritech:machine_core_6)、[薛定谔保险柜](@oritech:unstable_container)
和其他重型机器。
