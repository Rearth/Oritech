일부 기계는 작동하기 위해 추가 머신 코어가 필요합니다. 코어는 기계 자체에 대해 특정 위치에 배치해야 합니다.
기계에 필요한 코어 수는 기계의 툴팁에 나열되어 있습니다. 코어는 기계 간에 공유할 수 없습니다.

<Callout variant="info">
    더 좋은 코어를 사용해도 기계가 더 빨리 작동하지 않습니다. 코어는 추가할 수 있는 머신 확장기의 레이어 수에만 영향을 미칩니다.
</Callout>

멀티블록 건설을 시작하려면 먼저 기계 자체를 배치합니다.

기계를 우클릭하면 코어가 되어야 할 모든 블록이 몇 초간 하이라이트됩니다.
그곳에 코어를 배치할 수 있습니다. 또는 코어를 손에 들고 기계를 우클릭하면 자동으로 다음 코어가 배치됩니다.
이는 대상 위치가 장애물 없이 비어 있을 때만 작동합니다. 장애물이 있으면 블록이 대신 하이라이트됩니다.

각 머신 코어에는 품질이 연결되어 있습니다. 더 좋은 머신 코어를 사용하면 기계의 총 품질이 증가합니다.

기계의 결과 품질을 보려면 UI 좌측 상단의 기계 아이콘에 마우스를 올립니다.
기계 품질 자체는 기계 작동에 직접 영향을 미치지 않습니다. 대신, 기계에 추가할 수 있는 애드온 수를 결정합니다.
기계에 애드온을 추가할 계획이 없다면 가장 저렴한 코어를 사용해도 됩니다.
