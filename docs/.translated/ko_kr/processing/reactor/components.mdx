원자로는 여러 가지 구성 요소로 만들 수 있습니다:

- **원자로 컨트롤러**: 원자로의 핵심입니다. 이 블록은 벽 어딘가에 한 번 배치해야 합니다. 원자로를 조립/업데이트하려면 상호작용해야 합니다.
GUI에는 원자로의 현재 상태, 구성 요소의 온도, 통계가 표시됩니다. GUI는 내부의 첫 번째 레이어만 표시합니다.

- **원자로 벽**: 원자로 벽은 매우 강하고 높은 폭발 저항성을 가진 원자로 부품입니다. 전체 프레임을 감싸야 합니다.

- **원자로 봉**: 원자로 봉은 우라늄 또는 플루토늄 펠릿을 공급해야 하는 내부 구성 요소입니다. 각 봉 스택 위에 연료 포트가 필요합니다.
단일, 이중, 사중 연료봉으로 제공되며, 봉의 수에 따라 열과 에너지를 생성합니다.

- **원자로 열 파이프**: 열 파이프는 인접한 연료봉에서 열을 흡수한 다음, 인접한 열 배출구에 열을 분산시킵니다. 인접 구성 요소에서 전달되는 최대
열량은 두 구성 요소 간의 온도 차이에 기반합니다:
  > temperatureDiff / 4 + 10

- **원자로 중성자 반사경**: 이 블록은 인접한 연료봉의 중성자를 반사하여 효율을 높입니다.

- **원자로 열 배출구**: 배출구는 가장 뜨거운 인접 구성 요소에서 열을 제거합니다. 제거되는 열량은 인접
구성 요소의 온도에 기반합니다. 더 뜨거운 구성 요소는 더 많은 열이 제거됩니다. 정확한 공식은:
  > neighborHeat / 100 + 4

- **원자로 열 흡수기**: 열 흡수기는 모든 인접 구성 요소에서 고정된 양의 열을 제거할 수 있습니다. 냉각이 필요한 구성 요소로 둘러싸여 있을 때
더 효율적입니다. 그러나 흡수기 스택 위의 냉각제 포트에 얼음(또는 푸른 얼음/꽁꽁 언 얼음) 형태의 냉각제를 지속적으로 공급해야 합니다.
사용되는 냉각제의 양은 고정이며, 냉각되는 면이 많아져도 증가하지 않습니다. 매 틱마다 각 이웃에서 **16** 단위의
열이 제거됩니다.

- **원자로 에너지 포트**: 에너지 포트는 원자로가 생성한 에너지를 출력하는 데 사용됩니다. 각 포트는 최대 25,000 RF/t를 출력할 수 있습니다.

- **원자로 연료 포트**: 원자로의 외부 천장에 배치해야 하며, 아래에 연료봉이 있어야 합니다. 연료 펠릿을 삽입하는 곳입니다.

- **원자로 냉각제 흡수기 포트**: 원자로의 외부 천장에 배치해야 하며, 아래에 열 흡수기가 있어야 합니다.
얼음/푸른 얼음/꽁꽁 언 얼음 형태의 냉각제를 삽입하는 곳입니다.

- **원자로 레드스톤 포트**: 레드스톤 포트에 에너지 신호를 보내면 새로운 연료의 투입이 비활성화됩니다. 이미 연소가 시작된 연료 펠릿은
레드스톤 신호로 원자로가 완전히 정지하기 전에 마무리해야 합니다. 포트는 비교기와 함께 사용하여 데이터를 출력할 수도 있습니다. 3가지 모드가 있습니다:
에너지, 활성 봉 수, 온도. 모드를 전환하려면 포트를 우클릭하면 됩니다.

## 연료봉 활동

각 연료봉은 위의 연료 포트에서 고정된 양의 연료를 소비합니다. 각 연료 펠릿에는 다른 연료 용량이 있습니다. 특정 용량 데이터는 JEI/REI/EMI를 사용하여 펠릿
사용량을 확인하세요. 각 단일 봉은 1 용량 단위를 사용하고, 이중 봉은 2, 사중 연료봉은 4를 사용합니다.

연료를 태울 때 각 봉은 중성자 펄스를 생성합니다. 각 펄스는 특정 양의 에너지를 생성합니다 (기본 64). 봉이 받는 펄스가 많을수록
더 많은 에너지도 생성합니다.
각 봉은 기본적으로 하나의 펄스를 보내고 받습니다. 그러나 인접 구성 요소도 연료봉이면,
인접 구성 요소에 펄스를 추가로 보냅니다. 중성자 반사경은 펄스를 원래 위치로 돌려보내는 데 사용할 수 있으며, 인접한 봉 유형과 유사하게 작동합니다.

이중/쿼드 펄스는 같은 블록의 다른 봉에 펄스를 보내고, 이웃에 2 또는 4개의 펄스도 보냅니다.

단일 봉은 1개의 내부 펄스를, 이중 봉은 4개, 사중 연료봉은 12개를 생성합니다.

발생하는 열량은 봉의 총 펄스 수(내부 + 외부 펄스)에 기반합니다:
> pulses / 2 * pulses + 4
