정제소는 아이템과 유체를 가공하는 데 사용할 수 있습니다. 1개의 아이템과 1개의 유체 입력 슬롯이 있으며, 1개의 아이템과 3개의 유체 출력 슬롯이 있습니다.

<center>
<ModAsset location="oritech:area/refinery" width={1000} />
</center>

그러나 기본적으로 1개의 유체 출력 슬롯만 활성화되어 있습니다. 나머지 2개의 출력 슬롯을 활성화하려면 위에 정제소 탱크 모듈을 추가합니다. 이들도 머신 코어로 조립해야 하는 멀티블록입니다. 정제소 자체와 정렬되어야 연결됩니다. 출력 탱크 2와 3의 출력 유체는 메인 정제소 블록이 아닌 모듈에서 추출할 수 있습니다.

모듈이 활성화/사용되지 않을 때, 나머지 유체는 초기 출력에 대신 사용됩니다. 즉, 첫 번째 슬롯의 아이템과 유체 출력이 2배가 됩니다.
모듈이 하나만 설치된 경우, 두 번째 유체 출력량이 대신 2배가 됩니다. 이는 원래 출력될 유체가 1개 이상인 경우에만 해당됩니다.
