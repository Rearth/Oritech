원심분리기는 아이템을 분리하고 변환합니다. [파편 제련기](../processing/fragment_forge)에서 얻은 광석 덩어리로부터 광석 가루를 추출하거나,
석탄 가루를 탄소 섬유 가닥로 만들거나, [유체 애드온](../processing/addons)을 사용하여 오일이나 밀을 플라스틱 시트로 가공할 수 있습니다.

<Callout variant="info">
    유체를 가공할 때는 원심분리기가 유체를 받아들이기 전에 유체 애드온을 추가하고 초기화해야 합니다.
    유체는 애드온이 아닌 원심분리기에서 직접 펌프로 넣고 뺄 수 있습니다.
</Callout>
