자원 노드는 월드 곳곳에서 발견되며, 기반암 층 바로 위에 클러스터로 나타납니다.
모든 유형의 오버월드 광석을 포함하며, 일반적으로 작은 [원유](../resources/crude_oil) 웅덩이로 덮여 있습니다.

자원 노드는 [기반암 추출기](../interaction/deepdrill)로만 채굴할 수 있습니다.

표면에서는 [광석 덩어리](../resources/ore_boulder)의 존재로 자원 노드 클러스터의 위치를 확인할 수 있습니다.
광석 덩어리는 클러스터에서 발견되는 광석의 유형도 나타냅니다.
