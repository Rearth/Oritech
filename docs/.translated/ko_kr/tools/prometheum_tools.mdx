프로메테움 곡괭이는 고급이며, 파괴되지 않고, 마법부여 가능한 도구로 곡괭이 기능을 합니다.

프로메테움 곡괭이에는 두 가지 모드가 있습니다: **섬세한 손길**과 **범위** (3x3 채굴). 모드를 전환하려면 Shift를 누르고 우클릭하세요.

<ModAsset location="oritech:promethium_axe" />

프로메테움 전투 도끼는 또 다른 고급이며, 파괴되지 않고, 마법부여 가능한 도구로 도끼 기능을 합니다.
