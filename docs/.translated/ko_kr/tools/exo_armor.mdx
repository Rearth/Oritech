엑소 갑옷는 모험을 도와주도록 설계된 특수 슈트입니다. 각 부위는 고유한 이점을 제공합니다:

- **헬멧:** 야간 투시를 제공합니다.
- **흉갑:** 인벤토리 아이템을 충전하여 광산에서 더 오래 머물 수 있게 합니다.
- **각반:** 달리기 속도를 향상시킵니다.
- **부츠:** 낙하 피해 면역을 부여합니다.
