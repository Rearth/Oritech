[블록 설치기](../interaction/block_placer), [블록 파괴기](../interaction/block_destroyer), [비료기](../interaction/fertilizer)는 모두
기계 프레임으로 구축된 갠트리 위에서 작동합니다. 기계 프레임은 기계가 작동하는 영역을 지정합니다. 직사각형이어야 하며 내부가 비어 있어야 합니다.

기계는 항상 프레임 **아래**의 블록을 대상으로 합니다.

<Callout variant="warning">
    기계는 프레임의 모서리에 설치할 수 없습니다.
</Callout>

여러 대의 기계가 동일한 기계 프레임에서 작동할 수 있습니다. 프레임에 여러 기계를 배치하기만 하면 됩니다. 기계는 프레임 영역의 모든 블록을 순회합니다.

기계 프레임에서 작동하는 모든 기계는 대부분의 애드온을 사용할 수 있습니다.

속도 애드온은 프레임에서 작동하는 기계의 이동 속도와 작동 속도를 모두 증가시킵니다.
