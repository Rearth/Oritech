### 説明
レンチは配管の編集や切断に使用する工具です。配管の各独立方向における接続状態の変更や、配管の切断に使用します。

### 使用方法
#### 配管接続の切り替え
すべての配管は、それぞれの方向に対して接続状態を切り替えることができます。配管接続を切り替えるには、
既存の接続部分を右クリックして無効化します。接続を有効にするには、配管の中心部分を右クリックし、
接続を有効にしたい方向に対応する側面をクリックします。

#### 配管の切断
配管を切断するには、レンチを持った状態でシフトキーを押しながら配管を右クリックします。配管は即座にアイテムとしてドロップします。
また、レンチをピッケルのように使用して配管を切断することも可能です。レンチは配管切断時の採掘速度が通常のピッケルよりも速くなっています。
