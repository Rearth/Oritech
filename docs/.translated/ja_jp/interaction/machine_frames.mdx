[ブロック配置機](../interaction/block_placer)、[ブロック破壊機](../interaction/block_destroyer)、および[肥料散布機](../interaction/fertilizer)はすべて、機械フレームで構築されたガントリー上で動作します。機械フレームとは、機械が動作する作業領域を指定するもので、長方形で内部が空の状態である必要があります。

機械は常にフレームの**下側**にあるブロックをターゲットとします。

<Callout variant="warning">
    フレームの角部分には機械を設置できませんのでご注意ください。
</Callout>

同じ機械フレーム上で複数の機械を同時に稼働させることが可能です。この場合、単に複数の機械をフレーム上に配置するだけで構いません。機械はフレーム領域内のすべてのブロックに対して順次処理を行います。

機械フレーム上で動作するすべての機械は、ほとんどのアドオンを使用することができます。

速度アドオンを使用すると、フレーム内で動作する機械の移動速度と作業速度の両方が向上します。
