ブロック配置機は、自身のインベントリからブロックを取り出し、[機械フレーム](../interaction/machine_frames)の下層レイヤーに配置します。農地に種を蒔いたり、苗木を植えたりする際にも使用できます。

これ以上特に説明することはありません。
