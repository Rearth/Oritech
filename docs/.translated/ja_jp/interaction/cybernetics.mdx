サイバネティック拡張機能センターは、身体にサイバネティック拡張機能を装着できる施設です。
これらの拡張機能には、筋力や速度の向上、防御力の強化など、さまざまなメリットがあります。
また、暗闇でも視認できる能力や、自動的に栄養補給が行われる機能など、新たな能力を付与することも可能です。

<Callout variant="info">
    拡張機能はプレイヤーに永続的に適用されるアップグレードであり、維持のためにエネルギーやリソースを消費することはありません。
</Callout>

### 研究要件
すべての拡張機能は、まずサイバネティック拡張機能センターで研究する必要があります：
1. 組み立てられた機械の中に入って、「研究＆適用」GUIを開きます
2. 各拡張機能には独自のエネルギー消費量とリソースコストがあります（これらはセンターの保管庫またはプレイヤーのインベントリに保存されます）
3. 機械のインベントリにアクセスするには、機械を右クリックするか、GUIの左下にあるボタンを使用します
4. 多くの研究には、技術ツリーに示されているように前提条件となる拡張機能が必要です

### 研究ステーション
- 拡張機能センターには3つのマルチブロック研究スロットがあります（アドオンスロットと同様の仕組みです）
- 各ステーションの要件：
  - 3つの機械コアが必要
  - 1つの研究を同時に処理可能
  - 同じ種類のステーションを複数設置すれば、並行研究が可能になります

### 適用プロセス
1. 研究が完了した拡張機能は装着可能になります
2. 適用には追加のリソースが必要です
3. センターには研究したすべての設計図が保存されます（機械ごとに保存されるため、機械が破壊されるとデータは失われます）
4. 既存のプレイヤー用拡張機能は、UIのインポートボタン（左下）を使用してスキャンできます

### 拡張機能の管理
- すべての拡張機能は永久的に装着されます（維持やエネルギー消費は不要です）
- 一部の拡張機能は切り替え可能ですが、常に有効化されているタイプもあります
- 拡張機能はいつでも取り外し可能ですが、その装着に使用したリソースは失われます

### 切り替え操作
1. 拡張機能のホットキーを押し続けます（デフォルトは[G]キー）
2. 放射状UIで目的の拡張機能にカーソルを合わせます
3. キーを離すと切り替えが完了します

### modpack開発者向け情報：
拡張機能は完全にカスタマイズ可能でデータ駆動型です。新しい拡張機能はデータパックを使用して作成できます。拡張機能には3つのタイプがあります：
プレイヤーの属性を変更する「モディファイア拡張機能」（速度やリーチなどの属性に影響します）、ポーションと同様の効果を付与する「効果属性拡張機能」、そして鉱石視認機能やポータル拡張機能などの「カスタム拡張機能」です。これらのカスタム拡張機能はデータパックで参照可能ですが、そのロジックは完全なJava modとして実装する必要があります。

完全に新しい拡張機能はデータパックで作成可能で、既存の拡張機能も変更できます。拡張機能の定義例については、以下のファイルをご参照ください：https://github.com/Rearth/Oritech/blob/1.21/common/src/main/generated/data/oritech/recipe/augment/attackdamage.json

新しい拡張機能を追加する際には、翻訳エントリとテクスチャも必要になることをご注意ください。テクスチャは「oritech/textures/gui/augment」ディレクトリに配置してください。
