Fluid version of the Creative Energy Storage.
Provides infinite fluid or acts as an infinite void.

## Usage
*   **Creative Mode Only**: For testing and development
*   **Functionality**: Simulates infinite sources (like an ocean) or infinite drains
*   **Bucket Interaction**: Use a bucket to set the fluid type
