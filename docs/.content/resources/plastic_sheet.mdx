Plastic is a useful polymer used for insulators, casings, and many mid-to-late game components.

There are two main ways to produce plastic in Oritech:
1. **Bio Path**: Process [packed wheat](@oritech:packed_wheat) in a [centrifuge](@oritech:centrifuge_block)
with water to obtain raw biopolymer, which can then be centrifuged again with water to produce plastic sheets.
2. **Oil Path**: Refine crude oil in a [refinery](@oritech:refinery_block)
to obtain naphtha. Process naphtha in a centrifuge with sand to get polymer resin,
which can be smelted into plastic sheets. This route takes more setup, but it also produces more plastic.

Plastic is used in high-tier machine parts and advanced automation components.
