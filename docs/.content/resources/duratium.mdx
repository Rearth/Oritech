Duratium is a high-tier alloy used to create [particle accelerators]($PARTICLE_ACCELERATION)
and [reactors]($NUCLEAR_REACTOR). It is a very dense material.

Duratium can be created in two ways:
- In the [foundry](@oritech:foundry_block) by alloying [platinum](@oritech:platinum) and Netherite.
- In the [atomic forge](@oritech:atomic_forge_block) using [platinum](@oritech:platinum)
and [reinforced carbon sheets](@oritech:carbon_plating).
