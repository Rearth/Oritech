Biosteel is a mid-tier alloy used to create [addons]($ADDON_CONCEPTS), [sensors](@oritech:accelerator_sensor),
and various other components.

Biosteel can be created in the [foundry](@oritech:foundry_block) using steel and [biomass](@oritech:biomass).
