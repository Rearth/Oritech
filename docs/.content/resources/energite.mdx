Energite is a high-tier alloy used to create advanced power-related components and machines.
It is essential for high-capacity energy storage and advanced power distribution.

Energite can be created in the [foundry](@oritech:foundry_block) by alloying [nickel](@oritech:nickel)
and [fluxite](@oritech:fluxite).
