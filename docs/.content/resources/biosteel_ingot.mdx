Biosteel is a greener alternative to steel. It is a mid-tier alloy used to create [addons]($ADDON_CONCEPTS), [sensors](@oritech:accelerator_sensor),
and other components.

It can be created in the [foundry](@oritech:foundry_block) using iron and [biomass](@oritech:biomass).
