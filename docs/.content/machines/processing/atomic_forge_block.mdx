The atomic forge is a powerful machine capable of creating advanced
computer chips, reinforcing deepslate, and also plays a role in high yield ore processing.

<Callout variant="warning">
    Energy pipes cannot connect directly to an atomic forge; it needs 
    to be powered by an [enderic laser](@oritech:laser_arm_block).
</Callout>

## Automation

The atomic forge has different input modes to make automation easier. "Fill-Evenly" or "Sided" variants can be used to ensure each item goes in the right slot.

Automation can also be done via AE2 / RS2. Pattern providers work out of the box with the assembler.

## High-Energy Processing

Unlike other machines, the atomic forge's processing cycle is 
determined by its energy buffer. The recipe will only complete once 
the forge has been fully charged to the required level.
Using multiple lasers (or increasing their speed) can significantly speed up this process.
