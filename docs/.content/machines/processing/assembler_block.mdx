---
title: Assembler
id: oritech:assembler_block
type: block
---

The assembler features a 2x2 crafting grid and will automatically 
assemble items as long as it has energy, items in the input slots, 
and space for the finished product in the output slot.

Some machine components can be crafted without an assembler,
but doing so consumes significantly more resources.

---

**Efficiency**

Using the assembler is the recommended way to produce complex
components like [motors](@oritech:motor) or
[magnetic coils](@oritech:magnetic_coil).
Crafting these components manually is possible but consumes more 
resources than using the assembler.
