The foundry specializes in creating all the alloys needed to make 
Oritech machines. 
While some of these alloys can be crafted by hand, doing so consumes 
significantly more resources than using the foundry.

---

**Precision Alloying**

The foundry provides exact ratios for complex metals like
[electrum](@oritech:electrum) and [biosteel](@oritech:biosteel).
It is a core part of mid-game progression, enabling the production of 
the higher-tier [machine cores](@oritech:machine_cores) needed for 
advanced automation.
