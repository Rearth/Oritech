The Spawner Cage is a structural component used to define the 
spawning area for a [Spawner Controller](@oritech:spawner_controller_block).

---

**Cage Assembly**

The cage must be built directly below the controller. 
The required dimensions of the cage depend on the size of the mob 
being spawned; larger entities like Ghasts or Wardens require 
significantly more cage blocks than standard zombies. 
When a controller is active, it will highlight the area where 
cage blocks are needed.
