Modular cores that determine the quality of multiblock machines. A better core will not automatically make a machine faster, it will **only allow more addon
extenders** to be connected.

**Crafting**
Machine cores are crafted in tiers, with each tier requiring specific materials.

*   **Tier 1**: Planks and a Crafting Table.
*   **Tier 2**: [Copper Ingots](https://minecraft.wiki/w/Copper_Ingot) (or [Iron](https://minecraft.wiki/w/Iron_Ingot)) and [Lapis Lazuli](https://minecraft.wiki/w/Lapis_Lazuli).
*   **Tier 3**: [Carbon Fibre Strands](@oritech:carbon_fibre_strands) (or [Nickel](@oritech:nickel_ingot)) and Redstone.
*   **Tier 4**: [Machine Plating](@oritech:machine_plating_block) and [Enderic Compound](@oritech:enderic_compound).
*   **Tier 5**: [Adamant Ingots](@oritech:adamant_ingot) and [Advanced Computing Engine](@oritech:advanced_computing_engine).
*   **Tier 6**: [Duratium Ingots](@oritech:duratium_ingot) and [Dubios Container](@oritech:dubios_container).
*   **Tier 7**: [Prometheum Ingots](@oritech:prometheum_ingot) and [Superconductor](@oritech:superconductor).
