The Machine Frame is the structural backbone of Oritech's larger
industrial machinery.
It acts as a base chassis for several complex multiblocks.

<center>
<ModAsset location="oritech:area/machine_frame" width={512} />
</center>

A machine frame is always built as a rectangle, with one or more gantry machines attached to it. The inner blocks of the frame should be empty.

---

**Applications**

It is required for constructing the following machines:
- **[Block Destroyer](@oritech:destroyer_block)**
- **[Placer Block](@oritech:placer_block)**
- **[Fertilizer Block](@oritech:fertilizer_block)**

When building these machines, the frames define the working length and
area.
Refer to the specific machine documentation for their usage.
