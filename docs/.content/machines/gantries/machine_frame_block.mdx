The Machine Frame is the structural base of Oritech's larger
industrial machines.
It acts as a base chassis for several complex multiblocks.

<center>
<ModAsset location="oritech:area/machine_frame" width={512} />
</center>

A machine frame is always built as a rectangle, with one or more gantry machines attached to it. The inner blocks of the frame should be empty.

---

**Applications**

It is required for constructing the following machines:
- **[Block Destroyer](@oritech:destroyer_block)**
- **[Placer Block](@oritech:placer_block)**
- **[Fertilizer Block](@oritech:fertilizer_block)**

The machines always target the blocks below the frame, and they can be attached anywhere along the frame, including the corners.

Multiple compatible machines can operate on the same frame. They iterate through the frame area instead of requiring one dedicated frame each.

Most frame-based machines can use the usual addon set, and speed addons improve both movement speed and work speed.
