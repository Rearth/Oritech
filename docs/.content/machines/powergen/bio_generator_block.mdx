Converts [biomass](@oritech:biomass) and other biological materials into energy.
A good way to recycle organic waste from your farms.

The base generation rate is 64 RF/t.
## Usage

Feed it biomass-derived fuels and other biological materials accepted by your recipe viewer.
This is a multiblock machine that needs [machine cores]($multiblocks) to work.

It is one of the easiest generators to automate if you already have tree farms, crop farms, or other systems that produce steady organic waste. Because it supports addons, it can stay useful well after the basic generator has been retired.

<Callout variant="warning">
    Keep a steady supply of biomass to run this continuously.
</Callout>
