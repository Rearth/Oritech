---
title: Speed Addon
id: oritech:machine_speed_addon
type: block
---

The Speed Addon is used to accelerate the processing time of a machine.
It reduces the base time required for each processing cycle by 50%.

However, this performance boost comes at the cost of energy efficiency,
increasing the energy consumption of the machine by 20%.
Multiple speed addons can be used on a single machine to further
decrease processing time.

---

**Processing multiplied**

When multiple speed addons are used, their effects are combined.
For example, two speed addons will reduce the processing time to 25% of the
original value (50% of 50%).
This allows for extremely fast processing at the cost of significantly
higher power requirements.
