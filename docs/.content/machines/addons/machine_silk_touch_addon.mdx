title: Silk Touch Addon
id: oritech:machine_silk_touch_addon
type: block
---

The Silk Touch Addon allows automated mining machines to harvest
blocks directly instead of dropping their usual resources.

This addon is applicable to:
- **[Block Destroyer](@oritech:destroyer_block)**
- **[Enderic Laser](@oritech:laser_arm_block)**

<Callout variant="warning">
    If both a Silk Touch Addon and a
    [Yield Addon](@oritech:machine_yield_addon) are installed on the
    same machine, Silk Touch will take priority.
</Callout>
