The Heart of the Machine is a lategame multi-functional addon that
provides a wide range of industrial benefits in a single block.

---

**Combined Addons**

This addon is extremely powerful, but it comes with a strict limitation:
it only functions if it is the **first and only** addon attached to the
machine.
If any other addons or extenders are present, the Heart of the Machine
will remain inactive. Its main purpose is allowing machines with many addons to be
more compact.

It provides the benefits based on the addons connected to the [Addon Splicer](@oritech:shrinker_block) during creation.
Note that only addons that influence the statistics of a machine can be compacted this way. The steam boiler addon, redstone addon, inventory proxy addon, hunter addon,
or anything else that needs an interaction directly with the addon can not be compacted.
