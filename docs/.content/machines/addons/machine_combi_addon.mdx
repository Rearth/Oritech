The Heart of the Machine is a legendary multi-functional addon that
provides a wide range of industrial benefits in a single block.

---

**Unique Synergy**

This addon is extremely powerful, but it comes with a strict limitation:
it only functions if it is the **first and only** addon attached to the
machine.
If any other addons or extenders are present, the Heart of the Machine
will remain inactive.

It provides the following combined benefits:
- **Burst Processing**: Includes the 8x speed boost common to
[Burst Addons](@oritech:machine_burst_addon).
- **Automation Filters**: Integrates [Crop Filter](@oritech:crop_filter_addon)
and [Fluid Addon](@oritech:machine_fluid_addon) capabilities.
- **Resource Yield**: Provides [Yield](@oritech:machine_yield_addon) and
[Silk Touch](@oritech:machine_silk_touch_addon) effects.
- **Distance**: Increases the operational range like a
[Quarry Addon](@oritech:quarry_addon).
