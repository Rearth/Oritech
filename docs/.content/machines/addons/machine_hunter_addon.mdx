The Hunter Addon modifies the targeting system of the
[Enderic Laser](@oritech:laser_arm_block), allowing it to target and
attack living entities instead of just blocks.

---

## Combat Application

Once installed, the laser will scan for mobs within its beam path.
Each additional hunter addon increases the effective scanning distance
and improves the laser's ability to track moving targets.
This can be used to create automated base defense systems or
specialized mob farming setups.

Speed addons make the laser deal more damage. Efficiency addons reduce its RF/t use. Yield addons do **not** increase the loot dropped.

Loot from killed entities is automatically collected in the laser's inventory. XP orbs are not dropped when an entity is killed by the laser.

## Configuration

To change what kind of targets the laser shoots, shift-right-click it with a target designator in hand.
It cycles through the following options:
- All non-player mobs
- Hostile and neutral mobs (pets excluded)
- Hostile mobs only

It cannot be set to target specific mob types only. However, a crop filter addon lets it skip child entities.
