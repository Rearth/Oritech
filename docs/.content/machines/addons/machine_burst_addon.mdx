The Burst Addon allows machines to operate at much higher
speeds for short durations.
When active, it makes the machine run at 8x its normal speed.

Applicable to all recipe processing machines (e.g. pulverizers, furnaces, centrifuges, etc.)

Machines using burst addons can overheat if used for too long.
If the burst time is exceeded, the machine will enter a throttled state,
operating at 80% of its normal speed and consuming 20% more energy
until it has cooled down.

<Callout variant="info">
    Burst addons are best for intermittent processing tasks but are
    not recommended for machines that need to run continuously.
</Callout>

**Managing Bursts**

Each burst addon increases the maximum burst duration by 12 seconds.
To avoid overheating, the machine must stop processing periodically
to allow the burst meter to recharge.
When a burst addon is active, the machine UI will show the
remaining burst time.
