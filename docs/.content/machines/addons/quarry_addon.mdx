The Quarry Addon expands the operational range for automated excavation.

It is applicable to:
- **[Block Destroyer](@oritech:destroyer_block)**
- **[Enderic Laser](@oritech:laser_arm_block)**

---

**Large Scale Mining**

Installing this addon significantly increases the working area of the
machine, allowing it to clear much larger zones without being moved.
This is essential for setting up large-scale resource extraction pits.

On the block destroyer the mining depth is multiplied by 8 with each addon. On the enderic laser, it'll increase
the beam width by +1 with each addon.
