The Quarry Addon expands the operational range for automated excavation.

It is applicable to:
- **[Block Destroyer](@oritech:destroyer_block)**
- **[Enderic Laser](@oritech:laser_arm_block)**

---

**Large Scale Mining**

Installing this addon increases the working area of the
machine, allowing it to clear much larger zones without being moved.
This is useful for large-scale mining setups.

On the block destroyer, the mining depth is multiplied by 8 with each addon. On the enderic laser, it increases
the beam width by +1 with each addon.
