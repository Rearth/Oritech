Transports liquids between machines and tanks. The default transfer rate is 0.5 buckets every 3 ticks. Fluid pipes do not have internal storage.

## Usage
Connect pipes to any block with fluid handling. Right-click the relevant pipe part to toggle extraction. No wrench is needed.
However, a wrench can be used to disable pipe connections.

## Variants
*   **Standard**: Basic pipe model
*   **Framed**: Solid block version for wall integration
*   **Duct**: Alternative aesthetic style. Ducted variants do not connect to machines directly, only to other pipes.
