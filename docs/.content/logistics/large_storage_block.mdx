Advanced storage with much more capacity than the small version. Default capacity is 20M RF.

Energy can be inserted anywhere, but is only output at the 🔴 **red output marker**.

Addons can be used to increase the capacity or the throughput. Throughput statistics can be viewed via the machine GUI.
