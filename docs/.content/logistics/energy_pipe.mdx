Transfers energy (RF) between machines and power storage. The default transfer rate is 10,000 RF/t.

Power in Oritech is push-based, so generators and storage blocks push power into the pipes, which then send it to connected machines.
There is no extraction mode on the pipe itself. A wrench can be used to disable pipe connections.

## Variants
*   **Standard**: Basic stick-like pipe
*   **Framed**: Full-block variant for building integration
*   **Duct**: Alternative aesthetic style. Ducted variants do not connect to machines directly, only to other pipes.

<Callout variant="info">
    For very high power transfer, use [Superconductors](@oritech:superconductor) instead.
</Callout>
