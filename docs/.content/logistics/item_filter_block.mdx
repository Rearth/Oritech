title: Item Filter
---

To filter which items go where, you can use item filters. They are blocks you can place next to the target inventory.
They have five input sides and always output to the side they are facing.

They only accept items that match the filter set via the UI and automatically output them to the target inventory.
However, they will not automatically extract items from neighboring inventories. They also have an internal inventory of 1 slot.

<center>
<ModAsset location="oritech:area/item_filters" width={512} />
</center>

When placing them, ensure the single different output side is where you want the filtered items to go to.

<Callout variant="info">
If the "FTB Filters" mod is installed, you can use
the smart filters from that mod inside the item filter block.
</Callout>
