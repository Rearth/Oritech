title: Item Filter
---

Use item filters to control which items go where. They are blocks you place next to the target inventory.
They have five input sides and always output to the side they are facing.

They only accept items that match the filter set in the UI and automatically output them to the target inventory.
They do not automatically extract items from neighboring inventories. They also have a 1-slot internal inventory.

<center>
<ModAsset location="oritech:area/item_filters" width={512} />
</center>

When placing them, make sure the one different output side points where you want the filtered items to go.

<Callout variant="info">
If the "FTB Filters" mod is installed, you can use
the smart filters from that mod inside the item filter block.
</Callout>
