Most oritech machines (specifically the animated ones) can be repainted with different color schemes. To do so, machine paints can be crafted. 
They exist in 9 different variants,
each with a slightly different style.

To apply a new color to a machine, simple shift-click the machine with the paint in hand. If nothing happens, the machine can't be repainted.
