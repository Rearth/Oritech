A particle sensor can measure a particle's speed. A comparator can then provide a redstone signal based on that speed.

The following table shows the required speed for each redstone level:

1. 0
2. 10
3. 50
4. 75
5. 100
6. 150
7. 250
8. 500
9. 750
10. 1000
11. 2500
12. 5000
13. 7500
14. 10000
15. 15000

Sensors can be used as straight guides in the accelerator path.
