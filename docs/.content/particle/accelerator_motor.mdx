title: Accelerator Motor
id: oritech:accelerator_motor

custom:
    RF Capacity: "5,000,000"
---

Passing through an accelerator motor speeds up the particle by 1 m/s, as long as the motor is powered.

The power requirement increases with speed. Each time a motor speeds up a particle, it consumes the particle's
current speed * 10 RF.

Motors can be used as straight guides in the accelerator path.

For detailed information on particle acceleration mechanics, see the [particle accelerator guide]($particle_accelerator).
