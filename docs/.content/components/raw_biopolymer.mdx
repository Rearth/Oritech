An organic precursor to industrial plastics, derived from biological matter.

**Crafting**
- **Centrifuge**: Extracted from [Packed Wheat](@oritech:packed_wheat), [Solid Biofuel](@oritech:solid_biofuel), or Biomass Blocks using Water.

**Usage**
A versatile organic base for plastics, specialized fluids, and biological augments.
