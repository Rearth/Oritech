A powerful processor capable of handling complex logic and control systems.

**Crafting**
- **[Atomic Forge](@oritech:atomic_forge_block)**: Synthesized from a [Processing Unit](@oritech:processing_unit) and two [Silicon Wafers](@oritech:silicon_wafer).

**Usage**
Essential for high-level logic circuits, autonomous systems, and Tier 5 machine cores.
