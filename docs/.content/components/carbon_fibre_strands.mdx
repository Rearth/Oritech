A strong, lightweight material spun from carbon-rich substances.

**Crafting**
- **Centrifuge**: Produced by processing [Coal Dusts](https://minecraft.wiki/w/Coal) or similar carbon-based dusts.

**Usage**
A versatile material used to create reinforced sheets, levers, and mid-tier machine cores.
