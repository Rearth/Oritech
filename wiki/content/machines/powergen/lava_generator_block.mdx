Uses lava as fuel to generate electricity. A pump can be used to collect lava in large quantities.

Base generation rate is 64 RF/t. Sheol fire can also be used, and burns much longer than normal lava.

Fluid input can be automated with tanks, pumps, or pipes. Manual bucket filling is fine early, but the machine is much better once it is part of a proper fluid network.

<Callout variant="info">
    Sheol fire is worth refining specifically for this machine because it burns for much longer than plain lava.
</Callout>
