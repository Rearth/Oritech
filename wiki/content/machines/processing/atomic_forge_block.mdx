The atomic forge is a machine used to create advanced
computer chips, reinforce deepslate, and help with high-yield ore processing.

</center>


<Callout variant="warning">
    Energy pipes cannot connect directly to an atomic forge; it needs 
    to be powered by an [enderic laser](@oritech:laser_arm_block).
</Callout>

Unlike most machines, the forge does not just pay a constant RF/t cost. Each recipe has to charge the machine to a required energy level before it can complete.

That means your main bottleneck is usually laser throughput. More lasers, faster laser operation, and a dedicated power supply all increase production speed.

## Automation

The atomic forge has different input modes to make automation easier. "Fill-Evenly" or "Sided" variants can be used to make sure each item goes in the right slot.

Automation can also be done via AE2 / RS2. Pattern providers work out of the box with the forge.

## High-Energy Processing

Unlike other machines, the atomic forge's processing cycle is 
determined by its energy buffer. The recipe will only complete once 
the forge has been fully charged to the required level.
Using multiple lasers, or increasing their speed, can greatly speed up this process.

If the forge feels slow, item input is usually not the problem. Charge rate is.
