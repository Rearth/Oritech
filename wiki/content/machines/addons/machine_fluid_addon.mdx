---
title: Fluid Addon
id: oritech:machine_fluid_addon
type: block
---

The Fluid Addon enables fluid processing capabilities for machines
that otherwise only handle items.

It is specifically required for the following operations:
- For the [Centrifuge](@oritech:centrifuge_block) to process and
separate fluids.
- For the [Drone Port](@oritech:drone_port_block) to transport liquids.

<Callout variant="info">
    Once attached, the machine gains fluid storage and the corresponding
    fluid slots will be visible in the user interface.
</Callout>
