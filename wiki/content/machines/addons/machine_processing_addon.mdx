The Auxiliary Processing Chamber Addon allows a machine to process
multiple items or recipes simultaneously.
Each installed chamber addon adds one extra processing slot, meaning
the machine can complete two recipes in the time it would normally
take to complete one.

Applicable to all machines that process recipes (such as the pulverizer, centrifuge, assembler, etc.).

Adding 50% extra energy consumption per addon makes it more
power-hungry than standard machines.
This addon is best for bulk processing where throughput is
prioritized over efficiency.

---

**Parallel Processing**

Each cycle, the machine will attempt to start a new recipe for every
available chamber.
If you have three chamber addons, the machine can process four items at
the same time.
This is much more effective than speed addons for recipes that have a
very long duration.
