The Inventory Proxy Addon provides a dedicated access point for external
logistics systems to interact with a machine's internal storage.

Applicable to all machines with item slots.

---

**Targeted Access**

By default, machines might expose all their slots to pipes and conduits.
The proxy addon allows you to designate a specific slot that this
block represents.
Any items inserted into or extracted from the proxy will go directly
to the selected slot in the machine.

This is useful for complex assembly lines where specific input
or output slots need to be isolated.
