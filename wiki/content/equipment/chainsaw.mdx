The chainsaw is a fast tool for harvesting wood. It functions as an axe 
that never breaks, but it requires energy to run. It can also be used 
as a sword.

</Callout>

### How to use

Charge the chainsaw in a [charger](@oritech:charger_block) or by 
wearing an [exo chestplate](@oritech:exo_chestplate). If it runs out of 
energy, it becomes very slow.

#### Tree Felling
If you hold **Shift** while mining a log, the chainsaw will chop 
down the whole tree at once. This uses more energy for every 
block cleared.

#### Combat
The chainsaw counts as a sword, so you can use it to fight mobs. 
It is also very fast at clearing **cobwebs**.

<Callout variant="warning">
    The chainsaw is unbreakable, but it only works at full speed 
    when it has energy.
</Callout>

### Enchanting

You can use standard axe and sword enchantments like Efficiency, 
Sharpness, Silk Touch, and Fortune. Using **Unbreaking** will 
reduce the energy used for each operation. 

For better enchanting, check out the [enchanter](@oritech:enchanter_block).

If you want to automate wood collection, use a 
[treefeller](@oritech:treefeller_block) machine.
