Le Duratium est un alliage de [platine](^oritech:resources/platinum) et de netherite qui ne peut être fabriqué que dans une [fonderie](^oritech:processing/foundry).


Il est utilisé pour construire la [forge atomique](^oritech:processing/atomic_forge), l'[extracteur de bedrock](^oritech:interaction/deepdrill) et le noyau de machine ultra (niveau 6).
