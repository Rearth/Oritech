L'Energite est un alliage de [nickel](^oritech:resources/nickel) et de [fluxite](^oritech:resources/fluxite) qui ne peut être fabriqué que dans une [fonderie](^oritech:processing/foundry).


Il est utilisé pour les batteries, les modules de machine et les composants servant à créer certaines machines qui génèrent ou stockent de l'énergie.
