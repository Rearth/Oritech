Les gisements de ressources se trouvent partout dans le monde, apparaissant en clusters juste au-dessus de la couche de bedrock. Il existe des gisements de ressources pour tous les types de minerais de l'Overworld. Ils sont généralement recouverts d'une petite poche de [pétrole brut](^oritech:resources/crude_oil).

;;;;;

![gisements de ressources](oritech:textures/book/resource_node.png,fit)

Les gisements de ressources ne peuvent être minés qu'avec un [extracteur de bedrock](^oritech:interaction/deepdrill).

;;;;;

À la surface, la localisation d'un cluster de gisements de ressources peut être identifiée par la présence d'[gisement](^oritech:resources/ore_boulder). Le bloc de minerai indique également le type de minerais présents dans le cluster.
